# Campo Minado QTcreator

Projeto final da disciplina `Programação orientado a objetos` desenvolvido em C++ utilizando framework QTcreator. 

O tema `Campo minado` foi escolhido devido ao fato de que um projeto de programação pessoal do jogo Campo minado foi desenvolvido p´reviamente, contudo sua interface
era consolidada por console e linhas de comando. Assm, Utilizou-se a oportunidade de dar uma reformulada no visual e em seu modelo de programação para melhor se adequar a orientação a objeto.
